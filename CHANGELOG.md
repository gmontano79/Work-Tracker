# Work Tracker — Changelog

The entries below summarize significant functional milestones; earlier builds were shared as local application updates rather than formal Git tags.

## v1.5.11 — Clipboard images
- Added paste-from-clipboard screenshots to tickets, projects, tasks and notes, including thumbnail preview and removal.
- Embedded images in SQLite so full backups preserve them. No external image hosting required.

## v1.5.10 — Today and status filters
- Today includes active tasks without an assigned date.
- Added multi-select task status filters and quick presets for active/all statuses.

## v1.5.9 — Today tasks correction
- Active tasks without dates no longer disappear from the Today tab.

## v1.5.8 — Global search + Manuals
- Global search includes technical manual filenames and directory names; supports separators such as `_`, `-` and spaces.

## v1.5.7 — Manuals Library
- Added local read-only catalog of reference documents and media, with search, file open and refresh.

## v1.5.6 — Task due-date correction
- Corrected overdue totals to exclude tasks without assigned dates and completed tasks.

## v1.5.5 — Global Search
- Cross-module search for tickets, projects, tasks and notes, including keyboard shortcuts.

## v1.5.4 — Folder selection
- Improved note-folder selection and creation directly within note editors.

## v1.5.3 — Visual branding
- Added the custom Work Tracker icon to the desktop launcher, sidebar and browser tab.

## v1.5.2 — Folder management
- Added persistent note folders and safe rename/delete management.

## v1.5.1 — Note usability
- Added reading and copying modes, larger editor, Notes dashboard tile and card/list views.

## v1.5.0 — Notes Center
- Added personal notes, tags, pinning, archiving, custom colors and related-record links.

## v1.4.x — Ticket workflows, reports and desktop app
- Added transfer routing to other teams, detailed activity reports, richer project/task state changes, dashboard status summaries, and Windows quiet-launch shortcuts.

## v1.3 — Calendar and weekly PDF reporting
- Added week-scoped PDF reports, visible update history and deeper navigation.

## v1.0–v1.2 — Foundation
- Local SQLite storage and browser UI with tickets, projects/phases, tasks, CSV backups and edit workflows.
